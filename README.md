# SawitPRO-Data-Insights-Project
This project applies data discovery, exploratory analysis, and data visualisation techniques to generate actionable insights for SawitPRO, an agritech startup operating in Indonesia’s palm oil ecosystem. The objective was to analyse user behaviour, order fulfilment, production trends, and land expansion factors to support business growth, operational efficiency, and sustainability.

Multiple datasets were cleaned, transformed, and integrated, including app order data, user activity logs, global palm oil production and import statistics, and Indonesia palm oil concession data. Extensive data preparation was performed to handle missing values, standardise formats, engineer calculated fields, and remove irrelevant attributes, ensuring the datasets were analysis-ready.

Using Tableau, a series of exploratory visualisations and four thematic dashboards were developed: User Engagement, Order Fulfilment & Product Insights, Palm Oil Market Trends, and Concession Expansion. These dashboards revealed patterns such as regional differences in app usage, peak activity timings, product demand mismatches, declining yield efficiency over time, and how permit types and group ownership influence land expansion.

The findings led to clear, stakeholder-focused recommendations, including targeted user retention strategies, logistics and inventory optimisation, feature prioritisation within the app, and tailored support for smallholders versus group companies. Overall, this project demonstrates how data visualisation and storytelling can translate complex, multi-source datasets into insights that support strategic decision-making in a real-world industry context.

Key tools & concepts: Tableau, data cleaning, exploratory data analysis (EDA), dashboard design, calculated fields, data storytelling.
