# SawitPRO-Data-Insights-Project
Developed an interactive analysis dashboard in Tableau exploring palm oil industry data and app user engagement for SawitPRO, an agritech startup.

- Conducted data cleaning and transformation on multiple self-sourced CSV datasets including user activity, orders, and regional operations.
- Derived insights on user retention, market performance, and engagement trend to support SawitPRO’s growth strategies.
- Created four dashboards for business storytelling and decision support
